# Práctica de SQL: Análisis de Ventas de Tecnología

Resolución de consultas analíticas utilizando SQLite y Python en un entorno de notebook interactivo.

## Contenido de la Práctica

- **Entorno:** Base de datos en memoria (`sqlite3`) y manipulación tabular con `pandas`.
- **Tarea 1 - Selección Simple:** Catálogo ordenado alfabéticamente (`ORDER BY`).
- **Tarea 2 - Filtrado Crítico:** Filtro compuesto de país y precio unitario (`WHERE ... AND ...`).
- **Tarea 3 - Búsqueda de Nulos:** Detección de registros sin categoría (`IS NULL`).
- **Tarea 4 - Agregación:** Facturación acumulada por categoría comercial (`GROUP BY` y alias `ingresos_totales`).
- **Tarea 5 - Filtro de Agregaciones:** Filtrado posterior al agrupamiento mediante `HAVING` (> 10.000).
